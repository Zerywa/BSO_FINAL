# BSO_FINAL

AMBARENG Ini adalah website UMKM yang berisi tentang seputar Ambareng seperti menu gorengan Ambareng, promosi Ambareng, dan kontak Ambareng. Website ini dibuat 
hanya dengan menggunakan HTML dan CSS dengan perpaduan warna hitam, oranye tembaga, dan gold. Website ini hanya project front end.

Tujuan / Latar Belakang
Gorengan adalah camilan yang sangat dekat dengan keseharian masyarakat Indonesia, dan hampir setiap daerah punya inspirasi rasa serta cara olahnya sendiri. 
Ambareng hadir sebagai konsep usaha mikro, kecil, dan menengah (UMKM) kuliner yang ingin mengangkat keberagaman gorengan Nusantara tersebut dalam satu tempat, 
dengan harga seribuan per gorengan agar bisa dinikmati siapa saja. Untuk memperkenalkan usaha ini kepada calon pelanggan, dibutuhkan sebuah website yang
menampilkan cerita, menu, dan informasi kontak Ambareng secara menarik dan mudah diakses.

AMBARENG
Fitur home, fitur yang berisi tentang pengenalan umum dan pengenalan awal toko AMBARENG.
Fitur profil, fitur informasi yang berisi pengenalan lebih lanjut dan latar belakang toko AMBARENG.
Fitur main content, berisi menu-menu andalan yang tersedia di toko AMBARENG.
Fitur contact, fitur pelayanan di mana user dapat langsung menghubungi admin AMBARENG melalui akun media sosial ataupun email atau WA ketika ada keluhan maupun 
keperluan. 

Teknologi yang digunakan:
HTML, CSS, VSCODE, GITHUB, Claude Fable 5.1, ChatGPT Astra.

HOW TO RUN
1. Download source file final_BSO
2. Extract file final_BSO yang berbentuk ZIP
3. Tinggal jalankan saja file nya, bisa di jalankan dari home.html/profile.html/main-content.html/footer-contact.html
